# Multimodal extension
Run from repository root. Install `pip install -r requirements.txt`.
Copy your existing data/manifest.csv, data/folds.json and feature folders from your working repository. The ZIP snapshots did not include these data. Keep the original folds unchanged. If manifest is absent, put the raw CSV at data/mustard++_text.csv and run `python scripts/multimodal.py prepare`. Put target WAVs named by manifest target_key under data/processed/audio. If feature files are missing, run `python scripts/multimodal.py extract`. This downloads RoBERTa weights if not cached. Existing features may be reused if generated with the same extractors.
Run `python scripts/multimodal.py train` (or `--audio prosody` or `--audio opensmile`). Results in results/multimodal: per-fold metrics, predictions, summary, first-seed confusion matrices, ROC plots, classification reports, and final early/late models. Summary aggregates all 15 fold/seed runs. The text comparator uses logistic regression, not the original neural head. Late fusion uses fixed equal probability weights, SVC internal probability calibration is not speaker-group-aware; outer evaluation remains speaker-disjoint. Wav2Vec2 remains unimplemented and is not included in fusion. No scores are fabricated.
Predict: `python scripts/multimodal.py predict --text "Oh great, another exam" --audio data/processed/audio/example_u.wav --mode early`. Use matching utterance and recording. Only load trusted joblib files.
